# EPEAgents

一个面向“多智能体 + 隐私保护 + 教育个性化学习”方向的研究脚手架。该仓库提供了：

- **个性化学习仿真环境**：`PersonalizedLearningEnv` 将学生知识水平、疲劳度和好奇心建模为连续变量，方便做多任务/元学习实验。
- **多类型智能体**：包含基础策略智能体与带元学习偏好的智能体，可根据环境和 LLM 规划提示自适应调整策略。
- **联邦聚合与差分隐私**：`FederatedServer` 实现了裁剪 + 高斯噪声的聚合流程，帮助验证隐私保护下的协作学习。
- **LLM 规划提示**：`LLMPlanner` 通过解析环境描述和学生状态，为不同角色的智能体生成个性化学习建议。
- **训练管线与 Demo**：`TrainingPipeline` 将环境、智能体、LLM 与联邦聚合串联起来，`demo.py` 提供最小可运行示例。

## 快速开始

```bash
python demo.py
```

示例输出中会展示每轮联邦协作后的平均奖励，并打印出 LLM 生成的课程建议。你可以通过调整 `demo.py` 或直接使用 `TrainingPipeline` 来尝试新的主题、智能体类型、隐私噪声、训练轮数等配置。

## 下一步可以做什么？

- 将 `LLMPlanner` 替换成真实大语言模型接口（如 OpenAI、通义千问等），在 prompt 中注入学生画像。
- 扩展 `PersonalizedLearningEnv`，让奖励函数根据教育场景（如知识点掌握度、答题速度、学习动机）定制。
- 将 `MetaLearnerAgent` 接上梯度更新或少样本自适应算法（Reptile/MAML），并在联邦聚合前后对比表现。
- 接入真实的学习者日志或合成数据集，验证差分隐私策略对模型性能的影响。
